App Flow

TikTok authorization and posting review

Digital Donkey keeps publishing actions behind operator review. The app requests TikTok access only when an approved operator connects the @donkey.digital creator account for a specific business publishing workflow.

Terms of Service · Privacy Policy

1

Prepare

Review the product footage, vertical export, audio, caption, disclosure language, and product-card evidence before any TikTok action.

2

Authorize

Open TikTok Login Kit, request only the needed scopes, and return to the verified Digital Donkey callback URL after the creator account grants access.

3

Confirm

Read creator posting settings and privacy options. The operator sees the selected video, caption, and intended posting mode before submission.

4

Publish or upload

Use Content Posting API upload or direct-post workflows only for reviewed content. TikTok Studio remains available for exact Shop product-card verification.

5

Audit

Log the media file, caption, product-card note, TikTok publish status, timestamp, and any manual checks so the creator can verify the post later.

Requested TikTok scopes

  • user.info.basic: confirm the connected creator identity before publishing work is performed.
  • video.upload: upload approved video content for creator review where manual TikTok completion is required.
  • video.publish: test and use direct post only after the creator grants access and the workflow passes review.

Callback URL

The TikTok OAuth redirect URI is https://blockoddslabs.com/digital-donkey/tiktok/callback.html. The callback page displays the authorization result for the operator and does not sell, share, or expose TikTok account data.
